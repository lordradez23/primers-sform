# Primers Intelligence Workspace (Frontend)

This is the high-fidelity user interface for the Primers Intelligence cognitive engine. It provides a real-time, interactive environment for architectural analysis and system auditing.

## Key Features

- **Interactive Avatar**: A reactive AI representative that mirrors system state and cognitive load through emotional states and parallax movement.
- **Neural Trace Panel**: Real-time streaming of the AI's internal reasoning steps, providing full transparency into the "thought" process.
- **Executive Dashboard**: A visually rich summary of structural integrity, complexity scores, and strategic insights.
- **Responsive Workspace**: Conversion-focused design using modern glassmorphism and motion dynamics.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Styling**: Tailwind CSS & CSS Modules
- **Rendering**: React Markdown with Mermaid support

## Local Development

From the root project directory:
```bash
npm run dev:frontend
```

The frontend will be available at [http://localhost:3000](http://localhost:3000).
Ensure the backend is running on port 8000 for full functionality.
